Spoon Subversion

Privacy Policy

Last updated: August 7, 2026

Application and controller

Spoon Subversion (“Spoon”) is a native macOS client for working with Subversion repositories and working copies. Wonderland LLC is responsible for the processing described in this Privacy Policy.

Local application data

Spoon stores project records, security-scoped folder bookmarks, interface settings, commit drafts, selections, and task history locally on the user's Mac. SVN credentials are stored in macOS Keychain. This information is used to provide the features requested by the user and is not uploaded to Wonderland LLC.

Spoon accesses only working-copy folders and external tools selected or authorized by the user through macOS system controls.

Subversion repositories

When the user performs an SVN operation, Spoon communicates with the repository server configured by the user. Repository URLs, authentication data, commit messages, selected files, and other SVN data may be transmitted to that server as required to complete the requested operation.

Wonderland LLC does not operate, receive, or control data sent to user-configured SVN servers. Processing by those servers is governed by their respective operators and policies.

Optional analytics and crash reports

Spoon includes Google Firebase Analytics and Firebase Crashlytics. These services are disabled until the user explicitly allows technical data collection in the first-launch dialog or in Spoon settings. The user can change this choice at any time.

When enabled, Firebase may process basic app interaction events, an app-instance identifier, app version, device and operating-system information, approximate location derived from an IP address, crash stack traces, and related technical diagnostic data.

Spoon does not set a Firebase user ID and does not send repository URLs, working-copy paths, file or repository contents, credentials, commit messages, diagnostic exports, or other user-authored SVN data as Firebase custom values or logs. Spoon does not use Firebase data for advertising, advertising personalization, or cross-app tracking.

Service providers

When optional technical data collection is enabled, Google processes analytics and crash diagnostic data on behalf of Wonderland LLC through Firebase Analytics and Firebase Crashlytics. Google's handling of this information is subject to its applicable terms and privacy documentation.

Firebase privacy information is available at firebase.google.com/support/privacy.

Diagnostics

Spoon can create a locally saved diagnostic package at the user's request. Diagnostic export is manual. Spoon shows the destination chosen by the user and does not automatically upload the package. The user decides whether and how to share it.

Retention and user controls

Local Spoon data remains on the user's Mac until it is removed through the app, its related Keychain items are deleted, or the app's data is otherwise erased by the user.

Disabling technical data collection stops future Firebase Analytics and Crashlytics collection by Spoon and removes unsent crash reports from the app. Data already transmitted to Firebase is retained according to the retention settings and policies applicable to those services.

Children's privacy

Spoon is a developer tool and is not directed to children under 13. Wonderland LLC does not knowingly collect personal data from children through Spoon.

Changes to this policy

Wonderland LLC may update this Privacy Policy to reflect changes to Spoon or applicable requirements. The date at the top of this page identifies the latest revision.

Contact
