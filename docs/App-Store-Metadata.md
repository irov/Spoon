## Description

Spoon is a native Subversion client designed for a clear, visual workflow on Mac.

Review local changes in separate Unstaged and Staged sections, select complete paths for a commit, and inspect readable unified or side-by-side diffs. Browse repository history, changed paths, branches, tags, and remote folders without leaving the app.

Spoon includes its own SVN toolchain, stores credentials in Keychain, and uses App Sandbox with access limited to folders selected by the user. Optional technical analytics and crash reports remain disabled until the user explicitly allows them.

Highlights:

- Visual local changes with tree and flat layouts
- Complete-path staging for selective SVN commits
- Unified and side-by-side text diffs
- SVN property changes shown alongside files
- Revision history and changed-path inspection
- Repository browser, branches, and tags
- Native light and dark appearance
- English and Russian localization
- Opt-in technical analytics and crash reporting

System requirements: macOS 15 or later and a Mac with Apple silicon. Intel-based Macs are not supported.
